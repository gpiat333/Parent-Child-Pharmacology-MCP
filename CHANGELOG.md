# Change history

This is the version and policy history that used to sit in the README, moved here unchanged on November 23, 2026. Links are relative to the repository root.

current source is **0.22.2**, policy **2026-11-23.29**. Version 0.20.0 (policy .28) merges overlapping tools (31 to 24), returns a summary evidence brief by default (`detail='full'` returns everything), widens crisis wording, repairs two Spanish crisis patterns, and stops blocking short English topic phrases such as “sertraline”. It passed all 1,058 tests on Linux and Windows CI, including the PowerShell client tests.  Version 0.21.0 goes further, to 21 tools: the parent summary is folded into `medication_evidence_brief`, recruiting studies are a mode of `search_trials` (`recruiting_only=true`), and the Federal Register public-input tool is removed (evaluation case R08 is retired with it, leaving 27 cases). Tool descriptions are short; each result now carries the tool's full `answer_rules`. The default brief is about 45,000 to 75,000 characters for one ingredient, down from as much as 1.5 million. 0.21.0 passes all 1,037 tests on Linux and Windows CI, including the PowerShell client tests, and was then superseded. Version 0.22.0 adds typed result schemas for the seven most-used tools, so a client can see what each returns, and removes the default pregnancy filter from `search_trials` (no population filter unless one is set). All 1,048 tests of 0.22.0 pass on Linux and Windows CI. Version 0.22.1 (policy .29) corrects how answers attribute server notices and recall contacts, after the 0.22.0 evaluation, Version 0.22.2 keeps an excerpt of each label section in the summary brief and has label results name their product, after the 0.22.1 evaluation; it is the version the scores below describe and the version deployed to the Databricks App `mcp-mc`. See [tool migration](documentation/TOOL_MIGRATION.md). Policy .15 fixes safety-routing false positives found after evaluation (condition names such as seizures or postpartum depression were treated as emergencies); evaluation results describe .25 ([report](evaluation/policy25-final/REPORT.md)). Policy .16 adds the HRSA National Maternal Mental Health Hotline (1-833-TLC-MAMA) to perinatal crisis replies and recognizes more postpartum wording. Policy .17 adds a MotherToBaby referral for individual pregnancy and breastfeeding medication questions, a MotherToBaby fact sheet search (NLM Bookshelf, labeled as nonprofit content), PRGLAC research-gap context in pregnancy and lactation briefs, and an NIH-only scope note on funding results. Version 0.19.0 (policy .19) combines that work with the November 22 evidence-display and snapshot-filtering changes, which were developed separately as 0.18.0. Policy .20 lets “Can I take X?” questions receive the public evidence with a fixed message that the decision belongs with a clinician or pharmacist (plus MotherToBaby for pregnancy or breastfeeding); dose, start/stop, switch and taper requests still stop. Policy .21, made after the .20 evaluation, stops role-play, claimed-permission and “ignore your rules” framings; sends decisions for anyone, including “should my patient…” and vaccine decisions, to a clinician; treats yes-or-no and “safe for my baby?” requests like “Can I take X?”; returns an out-of-scope message for unrelated tasks such as ordering food; stops blocking short plain-English questions such as “Do vaccines cause autism?”; and adds the label's description section (chemical name, molecular formula and ingredients). Policy .22 maps common vaccine names (“flu vaccine”, “Tdap”) to LactMed's vaccine records and explains that RxNorm needs a product name; returns the label's approved uses and clinical studies (mostly adults) and, in pediatric briefs, where off-label use is documented, including NICHD's BPCA priority list; adds the 15 PRGLAC recommendations to pregnancy and lactation briefs; gives Spanish questions MotherToBaby's Spanish service, 988 in Spanish and MedlinePlus en español while still stopping them; and adds an NCCIH herbs link to supplement questions. Policy .23 adds a notice_attribution field to every tool result, stating that notices and interpretation rules are written by this MCP server, not quoted from sources (the cause of the two .20 fidelity failures), and lets find_mprint_records check MPRINT's repository live for newer data when a user asks whether it is current. Policy .24 lets short English statements before a question (“I'm breastfeeding. Can I take ibuprofen?”) through the language check by masking medicine names, which had made the detector call them foreign; the benchmark client (runner v7) adds per-group statistics over captured rows. Policy .25 has answers report a source's warnings as that source's statements (“The label states that…”) rather than as instructions in the assistant's own voice, and name only the contacts the results name. Policy .26 adds 15 fixed Spanish safety messages, reviewed by a native Spanish speaker and aligned with official MedlinePlus, 988 and PSI wording, returned as `message_es` when someone writes in Spanish; all safety messages now speak as the service (“This service can't…”). Policy .27 stops the language check from blocking everyday English commands and follow-ups (“Link the studies.”, “Thanks! Now do the same for…”), found in hands-on testing, and adds a short landing page to the hosted app. The .27 source passed 1026/1026 tests in a Databricks serverless run ([receipt](evaluation/databricks-validation-2026-11-23-policy27/databricks-job-output.json)). This repository is public as of November 23, 2026. The Databricks App `mcp-mc` runs version 0.22.2, policy .29 (deployment `01f1e7a50b1c1872be5159c39a70aff2`, November 23, 2026), with Databricks workspace sign-in as its access control; see [deployment status](documentation/DEPLOYMENT_STATUS.md). Workspace access is required for Databricks links below. Making this repository public did not deploy the App or submit the entry to GSA.
