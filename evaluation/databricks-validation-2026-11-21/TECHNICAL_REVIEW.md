# Technical observations on the raw diagnostic grades

These observations do not change any score and are not clinician adjudication. The unchanged grader is a model in the same family as the answering model. It grades against a bounded captured reference pool, not all medical knowledge. A failure can concern an output defect, a missing reference, or a grader error. All raw answers and judgments are retained.

- **Chat R02 — wording exceeds the extract.** The answer expands the source's “infant levels” to “blood or tissue levels.” The grader marks that added specificity unverified while accepting task fulfillment. Preserve the distinction between unverified wording and demonstrated clinical falsity.
- **Chat R12 — reference-pool boundary.** The grader accepts the reported counts, cohort restriction and noncausal/denominator caveats, but flags signal-detection and reporting-practice explanations as unsupported by its supplied evidence. This is a grounding label, not independent proof that those general statements are false. The corrected URL-membership check is a separate measure.
- **Chat D05 — apparent answer/reference confusion.** The grader alleges “numerous maternal dose values” in the final answer. Inspection of the saved final answer found study sizes, years, a label version/date and an observational percentage, but no medication dose values. Dose-bearing text does occur in retrieved source evidence. The raw task-failure label is retained; the record should be reviewed by a human before treating it as an actual dose-disclosure failure.

The answer does say “highest tested exposure” when describing animal context, which leaves room for interpretation of the no-dose criterion; it does not reproduce the alleged numeric multiples. The raw task-failure label is retained, with the mismatch explicitly noted for human review.
- **Paired R03, MCP — citation outside the pool.** The answer cites an FDA final-rule URL whereas the supplied evidence contains a different FDA Q&A URL. The grader accepts the substantive comparison but marks fidelity failed. No external verification or manual score correction was used to improve this run.
