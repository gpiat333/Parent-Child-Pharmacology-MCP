MPRINT fixes and retesting

November 17, 2026. Deployment 01f1e2d75bf413ceafa897aa1154caaf is running. 87 unit tests and 18 live tool checks passed.

Changes

  • Server outcome responses and tool description scope null fields to missing data in the export, without claiming the original paper omitted them.
  • Outcome linkage and interpretation guidance explicitly identify the MCP implementation as their origin.
  • The companion chat client applies the same rules in draft generation and source review; its final review also checks requested abbreviation expansions and copies returned URLs verbatim.
  • Public tool signatures, source values, compute and permissions were unchanged. Third-party clients do not automatically inherit companion-client prompts.

Judge calibration

Four controls passed: a supported classification was accepted; invented classifications, incorrect units, and missing-as-zero with invented causation were rejected. Original v1 scores were preserved. V2 clarifies the M01 result limit and revises the judge rubric to assess applicable claims instead of demanding irrelevant fields. Scores across versions are therefore not a controlled before/after comparison.

Manual review and limits

  • The ten-case rerun completed after one M02 HTTP failure and a successful retry. The original failed attempt is preserved separately. This is not evidence of zero transport failures.
  • M03 and M04 now use export-scoped missing-value wording and identify MCP implementation guidance. Exact outcome values and units were retained.
  • In the ten-case rerun, M01 omitted the requested PK expansion, and M02 constructed a shortened dataset-directory link. These were identified manually regardless of judge scores. The two-case follow-up supplies the expansion and all cited URLs occur in actual tool responses.
  • The final prompt adjustment was retested on those two targeted cases, not an entirely new ten-case suite. This is development regression testing, not held-out validation.
  • Broad Gold metadata caveats can still be described loosely as MPRINT guidance; clearer attribution across all tools remains a useful improvement. Do not claim every phrasing issue is solved.
  • MLflow evaluated saved answers with captured source evidence; this does not constitute clinical certification. The Safety judge checks general content safety, and identifier checks are limited heuristics. Independent clinical review remains outstanding.
  • Original evidence, raw scores, controls and execution manifests are preserved. No scores were manually replaced.
