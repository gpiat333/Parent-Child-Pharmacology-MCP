NICHD integration checks

November 17, 2026. Two new tools deployed to mcp-mc; 19 tools total.

Scope

  • search_bpca_evidence: live NICHD BPCA/PTN index titles and direct summary links. No PDF contents retrieved.
  • search_nichd_studies: live public DASH study descriptions, publication links, explicit network membership, and access requirements. MFMU and Neonatal Research Network filters use the public search form. No controlled datasets accessed.

Validation

120 unit tests passed, including 15 new parser, validation, network, link, and server-wiring tests. Eight deployed checks passed: BPCA acyclovir, levetiracetam, oxycodone, negative result; DASH MFMU, neonatal, ampicillin, negative result.

Two chat probes returned source-linked answers. BPCA explicitly disclosed that PDF text was not retrieved. DASH cited ARRIVE and ALPS and explained controlled access. The DASH probe made an unnecessary additional search_mprint call; this is a routing-efficiency limitation. These probes were reviewed manually, not scored by MLflow or clinically certified.

Fix during deployment verification

The first endpoint check exposed a missing server import (NameError). Added the import and a server-wiring regression test, redeployed, and reran all eight endpoint checks successfully.

Limits

Public HTML can change; schema failures return errors rather than evidence absence. Search results are bounded and report truncation. BPCA searches titles, not document full text. DASH search is not a systematic review or a recruiting-trials list. The prior 32-answer MLflow benchmark predates these additions.
