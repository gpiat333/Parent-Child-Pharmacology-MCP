Which additions strengthen the Mother–Child Evidence MCP?

Research review • November 17, 2026

Recommendation: defer CDC PLACES from the core medication-evidence server. Prioritize BPCA/Pediatric Trials Network summaries, exact trial records and accessible article full text. Add DASH public study discovery next. Use the existing GSA PLACES server as a separate optional tool when there is a community-planning question.

1. CDC PLACES: useful context, weak fit for the current core

CDC describes PLACES as model-based local estimates, using BRFSS, Census and ACS inputs, across counties, places, census tracts and ZCTAs. Its health measures largely concern adults, with measure-specific denominators. It does not supply individual medication exposure, pediatric drug outcomes or pregnancy-specific safety estimates. CDC overview; measure definitions.

For this project, an appropriate question is: “What local adult health and access context should a maternal-health outreach team consider in these counties?” An inappropriate inference is: “This county’s depression prevalence estimates postpartum depression,” or “Local diabetes prevalence establishes metformin safety in pregnancy.” That distinction is an assessment of fit, not a claim that geography lacks value.

CDC cautions against using PLACES estimates to track local change over time or evaluate local intervention effects. Area comparisons need confidence intervals. Aggregated prevalence needs the relevant population denominators. Postal ZIP codes and census ZCTAs also require careful matching. CDC usage limitations.

If added later, keep community context separate from drug evidence. Return measure definition, denominator, geography/FIPS, crude versus age-adjusted value, confidence interval, data year, release year and source URL. Reject unsupported subgroup requests instead of relabeling adult estimates as maternal or pediatric statistics.

A code-level finding in GSA’s PLACES MCP

The inspected compute_summary_stats uses statistics.mean(values). It describes the distribution of area estimates; that mean must not be presented as population-weighted regional prevalence. Its reported median selects a nearby area record. This deserves explicit labeling if reused. The repository also uses a separate FastMCP package and newer dependencies than your pinned MCP SDK setup, so wholesale copying is not a drop-in integration. Source implementation.

4. Proposed implementation sequence

  1. Finish evidence reliability first. Enforce returned citation URLs, improve source identity checks and preserve null/truncation semantics. Do not add datasets merely to increase tool count.
  2. Add one NICHD capability. A proposed search_bpca_evidence could search a reviewed manifest of official summaries, with PMID/NCT/label links only when explicitly supported. This tool does not exist yet.
  3. Deepen existing retrieval. Proposed get_trial_record and get_article_sections would address full records and accessible article sections. Validate identifiers, source permissions, result limits and truncation.
  4. Add DASH discovery separately. A proposed search_nichd_studies should return public metadata and access requirements. Do not expose controlled participant data through the public app.
  5. Demonstrate optional composition. If a public-health planning use case is needed, let the same agent call this MCP and GSA PLACES independently. Clearly label population context separately from medication evidence.

Recommended architecture: retain the current focused Python MCP. Add small reviewed adapters under mc/, typed tool contracts in server.py, stable provenance fields and bounded outputs. Use separate external MCPs at the chat-client layer when their domain is distinct. An MCP wrapper is a delivery mechanism, not an additional evidence authority.

5. Acceptance tests for any extension

  • Exact identifier matching and combination-drug ambiguity, including no-match and invalid inputs.
  • Population, study type, date and source linkage preserved; uncertain linkage explicitly labeled.
  • Missing values remain missing, and registry status is not interpreted as an outcome.
  • Every citation resolves to the returned source record without generated revisions or identifiers.
  • Access-denied, timeout, partial, stale and truncated data remain distinguishable from no evidence.
  • New golden questions should test genuinely new capabilities. Preserve the existing 32-case regression benchmark and report results separately.

The earlier MLflow development scores cannot certify any newly added source or an external MCP. Independent clinical review is still outstanding.

6. Hackathon positioning

The strongest story is specialized evidence orchestration: one question can connect a normalized medication to lactation evidence, pediatric labels, studies and a versioned MPRINT record, while preserving what each source can and cannot establish. CDC PLACES would broaden the story into geographic public health. BPCA/PTN would deepen the same maternal-child medication story.
