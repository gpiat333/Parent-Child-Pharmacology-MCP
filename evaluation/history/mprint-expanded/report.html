MPRINT features and curated outcomes

MPRINT expansion deployed November 17, 2026. Deployment 01f1e2ceb2f91e24aa0d730f195b8f4b; 17 tools, 3 prompts, 1 resource.
Implemented requested features:
1. Plain-language study labels alongside raw Gold study-type text and every Silver classification. PK=pharmacokinetics, PE=pharmacoepidemiology, CT=clinical trial, with PD/PG/RCT and additional Silver categories handled; unrecognized source wording is preserved.
2. Optional verified RxNorm brand/synonym-to-ingredient resolution in search_mprint_gold (enabled at the public tool by default). Zoloft -> sertraline; Tylenol -> acetaminophen. Original input and canonical ingredient names are searched. This does not supply every synonym, and RxCUIs are not equated with MPRINT UMLS CUIs. Approximate/ambiguous found identities require confirmation. Lookup failures fall back to literal text with a warning. Multi-ingredient products explicitly warn that results may concern individual ingredients rather than the combination.
3. Optional population and study-type filters. Population matches are conservative textual groups: pregnancy, lactation, pediatric, postpartum, maternal, any. A generic Maternal label does not establish pregnancy or lactation. Mixed labels remain visible; filtering does not establish an exclusive cohort. Study-type filters recognize PK, PE, CT, PD, PG and RCT while retaining raw source text.
4. Snapshot coverage is explicit: revision, retrieval times, included tables, non-live status, row limits, matching counts and missing-evidence caveats. Refresh is not automatic.
5. New get_mprint_gold_outcomes(pmid,kind,max_results,offset). Includes 116,478 PE/CT outcome rows and 6,163 PK-summary outcome rows (122,641 total). Individual-patient PK outcome and PK-parameter tables remain excluded. Source statistics, values, units, uncertainty intervals, notes and exposure/group fields are retained as text with nulls for blanks. Source PMIDs ending in .0 are safely normalized; fractional or malformed IDs are rejected. No pooled effects, inferred denominators or causal claims are computed.
Outcome linkage: PMID plus original curation workbook and folder. This establishes study-source context, NOT cohort/arm matching or drug-specific effect attribution. 7,539 PE/CT rows and 1,717 PK-summary rows lack a matching metadata context under this strict join; they are returned with study_context_matched=false, not silently linked elsewhere. Original paper review remains necessary for ambiguous source fields. Pagination exposes omitted rows.
Architecture: server.py registers tool/schema changes; mc/mprint_data.py handles name expansion, filters, labels and read-only querying; mc/mprint_outcomes.py validates source imports. A separate pair of read-only outcome databases is selected by PMID parity, with compressed per-row payloads. All deployed database files are below Databricks' 50 MB per-file limit. Source revision remains 4bdee90dff3610816e86d0eed29b4c4d0fe76e89; MIT license retained.
Validation: 87 unit tests pass, including parser value/unit/null preservation, PMID normalization, conservative filters, ambiguous name handling, network failure fallback, provenance linkage and paging. All 18 deployed API checks pass across existing tools and the expansion. Two live chat runs completed. The outcome-row chat preserves the requested values/units/uncertainty fields and reports 2 of 8 matching rows. The brand/filter chat uses the features correctly but introduces ingredient RxCUI 36437, which was NOT in its captured tool outputs; this is an unsupported-provenance addition even if the identifier is correct. Do not call both chats fully source-grounded passes. No clinical certification claimed.
Reproduction: run companion build-mprint-snapshot.py then extend-mprint-outcomes.py (which calls split-mprint-outcomes.py), review provenance manifest and sizes, run project unit tests, then validate/deploy/run the bundle. No new compute or permissions created.
