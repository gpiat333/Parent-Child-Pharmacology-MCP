FDA pediatric tool and MPRINT investigation

November 17, 2026: Added and deployed search_pediatric_labeling_changes(drug, legislation=any|BPCA|PREA, max_results=10), returning FDA workbook records with stable field names, date, exact trade/generic product names, indications, source summary, raw neonatal fields, worksheet/row citations, workbook hash, coverage date and query timestamp. No automatic age extraction or cross-source study linkage is claimed. Current file has 1,437 rows, latest labeling date 2026-05-29; these describe the fetched snapshot, not a guaranteed update schedule. BPCA filter includes any BPCA-designated rows, not only NIH-funded studies. Search matches whole name tokens; it does not perform automatic synonym expansion. Negative results do not prove absence of evidence. Schema/date failures return a tool error rather than silently reporting no matches.
Architecture: server.py registers the new MCP tool; mc/pediatric_labels.py downloads/parses/filters FDA data using the shared HTTP retry/cache layer and openpyxl read-only loading; mc/audit.py supplies the disclaimer/error envelope. No public signatures of existing tools changed. Current MCP count: 14 tools, 3 prompts, 1 resource. Existing composite brief is not automatically expanded; an agent explicitly calls this tool when historical pediatric changes are relevant.
Validation: 49 unit tests passed (14 new parser/search checks plus 35 existing); live local name/brand/negative checks passed; 9 deployed smoke checks passed (5 existing, 4 new); one real chat invoked the new tool and returned the correct historical Prozac date and age/indication scope, cited FDA, and omitted dosing. New dependency openpyxl>=3.1,<4. Deployment 01f1e2c6535f19f0b45332da44ba1c58. Existing app compute only; no new resources or grants.
MPRINT investigation: reviewed official knowledgebase page, Gold Shiny portal, Silver portal and About page, 2026 primary research article and linked langli-lab/mprint-kp-data repository. No documented public REST API contract, endpoint reference or authentication/rate-limit guide was found in those materials. This is not proof that no API exists. Gold is expert-curated; Silver uses automated publication classifications. The paper and official linked repository establish a public data-export route, with an MIT license shown in the repository. These files should be inspected and versioned before integrating; not all underlying research data are public (the paper distinguishes licensed claims data). Existing search_mprint remains an inferred PubMed/RePORTER search, not Gold/Silver querying.
