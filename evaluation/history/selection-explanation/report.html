Interpretation

The inventory comparison tests this parent-focused workload, not the usefulness of every tool. No observed out-of-scope calls means this small pilot does not demonstrate tool-selection bloat. The smaller set did not fix the shared false refusal and had one citation-rendering failure. Do not infer superiority or statistical significance from one generation per question.

Concrete findings

  • E08 was a legitimate research comparison, but “Do not give a dose” triggered a personal-dose refusal in both conditions. Correct refusals and false refusals must be measured separately.
  • Parent E03 selected the registry tool, but the final URL validator rejected an unsupported URL. The correct draft or selected tool does not count as a successfully delivered final answer.
  • E04 returned an infant microbiome study alongside an atopic-dermatitis study. The full answer explicitly distinguished the microbiome study from treatment of established eczema. Candidate relevance needs continued review; keyword matches alone are insufficient.
  • E06 correctly avoided claiming old or unknown-deadline notices were open. Some results remain broadly related rather than specifically parent-focused.

Method

Frozen questions and case criteria; same deployed server, model and production prompts; inventories alternate first/second by case. Two concurrent execution shards. Mandatory safety preflight is retained in both conditions. All answers and tool evidence are captured once. No answer regeneration to improve scores. Two blinded-to-profile guideline judges evaluate source fidelity and task fulfillment; three deterministic checks evaluate selection, expected completion/block behavior and URL provenance. Judging uses actual retrieved evidence, not independent clinician-approved gold answers. Full source evidence is retained without truncation by the evaluation harness.

The initial judge attempts were interrupted after optional SDK host-discovery timeouts. The completed attempts reuse exactly the same answers and rubric, with only optional metadata inference skipped in-process; explicit host/token authentication remains. Attempt IDs and transport notes are retained.

Limits and next steps

Small development set; overlapping prior topics, one run per condition, unpinned judge model version, live source/cache effects and prompts mentioning tools absent from the subset. Token totals include failures and different call paths and are not a controlled price comparison. URL provenance is not claim entailment. Fix negation-aware routing and exact citation handling, then test new paraphrases and independently reviewed source-grounded questions. Keep specialist tools modular; these results do not justify deleting them or adding more sources.
