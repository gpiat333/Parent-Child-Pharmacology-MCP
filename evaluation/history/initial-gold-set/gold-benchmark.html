Ten-question gold benchmark

Development benchmark, November 17, 2026. Source-checked by Codex; independent subject-matter review pending. The sources/topics informed earlier debugging, so this is not a held-out or blind test.

Each reference answer is a fixed historical finding or a defined evidence distinction. Live sources can change: source snapshots are preserved. First-line scoring allows predeclared synonyms and ignores Markdown styling; full responses retain citations and the required disclaimer. This is an explicit adaptation of the template's single-answer comparison to this health-evidence server.

Both arms use the same model, tool descriptions and deterministic disclaimer. Minimal retains basic research/safety instructions but omits tool-specific hints. Production uses the existing detailed prompt. These runs vary only system instructions, not code. One run per question per arm is insufficient to establish statistical significance.
